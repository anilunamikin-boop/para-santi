# Tus fotos

Copiá acá las fotos que quieras usar en la galería y agregá su ruta, texto y descripción en `CONFIG.memories` dentro de `../script.js`.

Ejemplo de nombre de archivo: `recuerdo-01.jpg`. Se admiten los formatos habituales del navegador (JPG, PNG, WebP). Si una ruta todavía no existe, la página mostrará un recuadro decorativo.
